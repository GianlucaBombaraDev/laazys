# @gianlucabombaradev/laazys

Generate browsable documentation for Vue.js components and composables from their JSDoc comments.

```bash
npx laazys --path ./src --open
```

Requires Node.js 22+. See the [project README](https://github.com/GianlucaBombaraDev/laazys#readme) for installation from GitHub Packages, options and the supported JSDoc tags.
