# laazys-app

The web UI of [Laazys](../../README.md): Vue 3, Vite, Pinia and Tailwind CSS.

This package is not published on its own. `pnpm build` outputs it to `../laazys/app`, which the CLI serves together with the `/files` endpoint that provides the parsed documentation. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the development workflow.
